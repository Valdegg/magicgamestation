# 001 — Rough Structure

Explore the code base using mostly commands like `ls`, `tree` and `du`.

Your goal is to get a very rough idea of the different parts of the project
and the amount of effort it would take for either an expert engineer
or an LLM to get a quick gut feeling on each of them.

Also feel free to open `README.md`s, `Makefile`s, `pyproject.toml`s
or files that seem like they are highly likely to help achieve the above goal.

Avoid opening random code files that would be too time consuming to read at this stage.
